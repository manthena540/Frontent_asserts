# Client / TL Questions

## Project discovery

- What is the main goal of this website/app?
- Who are the users?
- What is the primary user action?
- What problem are we solving?
- What pages/screens are required?
- What is the expected launch date?

## Design

- Is there an existing brand guide?
- Which colors must be used?
- Which fonts are required?
- Are there websites you like?
- Are there websites you dislike?
- Should the design be minimal, premium, playful, technical, etc.?
- Light mode, dark mode or both?

## Content

- Who provides copy?
- Who provides images?
- Are logos available in SVG?
- Are testimonials/case studies available?
- Is content final or placeholder?

## Technical

- React, Next.js, Vue, Angular or another stack?
- Tailwind or another CSS approach?
- API available?
- Authentication required?
- CMS required?
- Analytics required?
- Deployment platform?
- Browser support?
- SEO requirements?

## UX

- What are the most important user journeys?
- What should happen after each major CTA?
- What should happen if an API fails?
- What should happen when there is no data?
- Are there existing usability issues?

## TL / code-review questions

- Does this component need to be reusable?
- Should this state live locally or globally?
- Is this logic better extracted into a hook?
- Are we duplicating UI?
- Is the API layer separated from presentation?
- Are loading/error/empty states handled?
- Is accessibility covered?
- Is the implementation over-engineered?

## Before delivery

- Who approves the UI?
- Who approves content?
- What devices/browsers must be tested?
- What is the acceptance criteria?
- Who owns post-launch fixes?
