# Text / Content

## Before writing UI text

Ask:

- Who is reading this?
- What do they need to know?
- What action should they take?
- Is this text necessary?
- Can it be shorter?
- Does the wording match the brand?
- Is technical language necessary?

## Common UI text

### CTA examples

- Get started
- Book a demo
- Learn more
- View case study
- Contact us
- Try it free
- Explore features
- View details

Prefer specific actions over vague labels such as `Click here`.

## Form text

Every important form should have:

- Label
- Helpful placeholder only when needed
- Validation
- Error message
- Success feedback
- Required/optional indication where useful

## Empty states

Structure:

1. What happened?
2. Why is the screen empty?
3. What can the user do next?

Example:

> No projects yet. Create your first project to get started.

## Error messages

Prefer:

> We couldn't load your projects. Try again.

Avoid:

> Error 500.

## Loading states

Use:

- Skeletons for content-heavy areas
- Spinners for short actions
- Progress indicators for long operations

## Microcopy checklist

- [ ] Clear
- [ ] Short
- [ ] Action-oriented
- [ ] Consistent terminology
- [ ] No unnecessary jargon
- [ ] Error messages explain recovery
- [ ] Buttons describe the action
