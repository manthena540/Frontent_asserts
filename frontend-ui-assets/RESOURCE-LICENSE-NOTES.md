# Resource / License Notes

Always verify the current license on the original provider before shipping a commercial project.

## Important rule

A resource being searchable/downloadable for free does not automatically mean every use is free.

Check:

- Commercial use
- Attribution requirements
- Redistribution restrictions
- Logo/trademark restrictions
- Modification rights
- SaaS/app embedding terms
- Whether the free tier has usage limits

## Record resources like this

```md
### Resource Name

- Type: Icons
- Price: Free / Paid
- License: MIT / ISC / Apache 2.0 / provider-specific
- Best for: ...
- Used in project: ...
- Source: ...
- Checked: YYYY-MM-DD
- Notes: ...
```

## Good practice

Keep the original source URL and the date you checked the terms. Licenses and pricing can change.
