# Images

## Free image sources

| Source | Best for |
|---|---|
| Unsplash | High-quality photography |
| Pexels | Stock photography and video |
| Pixabay | Photos, illustrations and media |
| unDraw | Open illustrations |
| Storyset | Editable illustrations |
| Openverse | Search across openly licensed media |

## Paid / premium sources

| Source | Best for |
|---|---|
| Adobe Stock | Professional stock photography, video and graphics |
| Shutterstock | Large commercial stock library |
| iStock | Stock photos, vectors and illustrations |
| Envato Elements | Subscription-based broad creative asset library |
| Freepik Premium | Graphics, vectors, templates and stock assets |
| UI8 | Premium UI kits and product design assets |

## Image rules

Prefer:

```text
AVIF/WebP when supported
Correct aspect ratio
Responsive sizing
Compression
Lazy loading for below-the-fold images
Meaningful alt text
Decorative images marked appropriately
```

## Example

```jsx
<img
  src="/images/team.webp"
  alt="CogniWissen team collaborating in an office"
  loading="lazy"
  width="1200"
  height="800"
/>
```

## Do not

- Download random Google Images and use them commercially
- Use copyrighted images without permission
- Use huge original images when a smaller asset works
- Put important text only inside an image
