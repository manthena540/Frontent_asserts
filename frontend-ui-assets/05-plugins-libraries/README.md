## Before installing a package

Ask:

- Do I really need it?
- Is native CSS/JS enough?
- Is it maintained?
- Is the license suitable?
- Does it add unnecessary bundle weight?
- Does it solve a repeated problem?
- Does it work with the current framework version?

## Dependency checklist

- [ ] Purpose documented
- [ ] License checked
- [ ] Bundle impact considered
- [ ] Security/advisories checked
- [ ] Version compatible
- [ ] Documentation link saved
